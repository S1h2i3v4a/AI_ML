## 🎯 Questions Ka Complete Index

1. **Problem 1 (Tax Bracket Calculator):** Salary input lekar slab ke mutabiq tax percentage (5%, 15%, 25%) calculate karna.
2. **Problem 2 (Even Numbers in Range $[a, b]$):** Do numbers $a$ aur $b$ ke beech ke sabhi even numbers inclusive print karna.
3. **Problem 3 (Print Digits of $N$):** Number ke sabhi digits ko $N \pmod{10}$ aur $N // 10$ se print karna ($N = 312 \implies 3, 1, 2$).
4. **Problem 4 (Count Digits):** Number ke total digits ki sankhya calculate karna.
5. **Problem 5 (Sum of Digits):** Number ke sabhi digits ka aggregate mathematical sum nikalna.
6. **Problem 6 (Divisibility by 3 & 5):** 1 se 100 tak ke un sabhi numbers ko print karna jo 3 aur 5 dono se divide hote hain.
7. **Problem 7 (Sentinel Input Loop):** User se lagatar input lena aur positive/negative batana jab tak user "Quit" na bole.
8. **Problem 8 (Simple Calculator):** `calculator(a, b, operation)` function banakar `+`, `-`, `*`, `/` execute karna.
9. **Problem 9 (Prime Number Verifier):** Number prime hai ya nahi check karna $\mathcal{O}(\sqrt{n})$ trial division loop se.
10. **Problem 10 (Number Guessing Game):** Secret number guess karne ka interactive game with "Too high", "Too low", "Correct!".
