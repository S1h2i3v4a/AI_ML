# Submodule 35.02: GitHub Account Banana (Hinglish)

## 1. GitHub Account ki Ahmiyat

GitHub account har software engineer aur data scientist ki professional identity hota hai. Tech companies aur interviewers resume ke sath aapka GitHub profile zaroor check karte hain taaki aapka real project work dekh sakein.

---

## 2. Step-by-Step Account Creation Guide

1. **Website par Jao**:
   - Browser mein `https://github.com` open karein.
2. **Sign Up par Click Karein**:
   - Top-right corner par **Sign up** button par click karein.
3. **Email ID Enter Karein**:
   - Apni active email ID enter karein.
   - **Zaroori Salah**: Hamesha apni permanent personal email (jaise Gmail) use karein. College ya university ki email graduation ke baad band ho sakti hai, jisse aapka saalon purana commit history aur portfolio access kho sakta hai.
4. **Strong Password Banayein**:
   - Letters, numbers aur special characters wala strong password set karein.
5. **Professional Username Choose Karein**:
   - Aapka username aapke profile URL ka hissa banega (`https://github.com/username`).
   - Hamesha professional naam rakhein (jaise `FirstnameLastname` ya `shivam-dev`). Ajeeb gaming nicknames avoid karein.
6. **Email Verification**:
   - Bot verification puzzle solve karein.
   - Email par aaya 8-digit verification code enter karein.
7. **Account Type Setup**:
   - Student ya Individual select karein aur Free Account choose karein.

---

## 3. GitHub Student Developer Pack ke Fayde

Agar aapke paas college ki `.edu` ya `.ac.in` email ID hai, toh aap **GitHub Student Developer Pack** ke liye apply kar sakte hain jisme:
- GitHub Copilot free milta hai.
- GitHub Pro account features free milte hain.
- Free cloud hosting credits (Azure, DigitalOcean) milte hain.
