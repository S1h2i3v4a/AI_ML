### 📋 Is Topic Mein Hum Kya Seekhenge?
- Official **Assignment 5** ke sabhi 5 fundamental questions ka detailed mathematical aur logical formulation.
- File write mode (`"w"`), append mode (`"a"`), aur read mode (`"r"`) ka practical application.
- List comprehension se high-performance data filtering aur thresholding logic.
- JSON module se persistent key-value configuration file banana, load karna aur update karna.
- Exception handling se `FileNotFoundError` catch karke system crash prevent karna.

### 🔍 Har Ek Point Ka Simple & Detailed Explanation

- **Problem 1 (Names Registry)**: User se ya predefined list se 5 names lekar unhe `names.txt` file me write karna, file close karna, aur phir wapas read mode me open karke print karna.
- **Problem 2 (Activity Logging)**: Server logs me purana data wipe kiye bina nayi activities append karna (`"a"` mode), aur full audit history verify karna.
- **Problem 3 (Threshold Filtering)**: `[5, 10, 15, 20, 25]` list me se `> 15` wale elements ko bina long for-loop ke single-line list comprehension se filter karna.
- **Problem 4 (City Population JSON Store)**: 3 cities ki population ko `cities.json` me save karna, file read karke print karna, aur user se nayi city lekar existing JSON me update karna.
- **Problem 5 (Safe File Opener)**: Missing `data.txt` file ko `try...except FileNotFoundError` block se handle karna taaki program crash na ho.
- **Problem 6 (Systems Engineering Log Analyzer)**: Enterprise scale access logs ko process karke incident report generate karna.
