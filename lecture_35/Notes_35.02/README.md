# Submodule 35.02: Creating a GitHub Account

## 1. Account Creation Overview

A GitHub account is the standard professional identity for modern software engineers, ML researchers, and data scientists. It serves both as your personal code repository and your verifiable engineering portfolio.

---

## 2. Step-by-Step Registration Workflow

1. **Visit Official Portal**:
   - Open your browser and navigate to `https://github.com`.
2. **Click Sign Up**:
   - Click the green **Sign up** button located at the top-right corner of the landing page.
3. **Enter Email Address**:
   - Enter your email address.
   - **Important Recommendation**: Always use a permanent personal email address (e.g., Gmail) rather than a temporary college or company email. College email access typically expires after graduation, which could lock you out of your career-long commit history and portfolio.
4. **Set Password**:
   - Create a strong, unique password comprising uppercase letters, lowercase letters, numbers, and symbols.
5. **Select a Professional Username**:
   - Your username forms part of your public profile URL (`https://github.com/username`).
   - Choose a clean, professional identifier:
     - Preferred: `FirstnameLastname` (e.g., `ShivamKeshari`)
     - If taken: Add meaningful suffixes or numbers (e.g., `DeltaStudent101`, `shivam-keshari-dev`).
     - Avoid unprofessional handles or temporary gaming tags.
6. **Email Verification**:
   - Complete the human verification puzzle.
   - Check your inbox for the 8-digit verification launch code sent by GitHub and enter it into the prompt.
7. **Personalization Questionnaire**:
   - Select your role (e.g., *Student / Software Developer*).
   - Select collaboration preferences (e.g., *Working individually* or *Working in a team*).
   - Select the Free Tier account.

---

## 3. GitHub Student Developer Pack

If you possess an active academic institution email (e.g., `.edu` or `.ac.in`), you can apply for the **GitHub Student Developer Pack**:
- Free access to GitHub Copilot (AI pair programmer).
- Free GitHub Pro account features.
- Cloud credits (AWS, Microsoft Azure, DigitalOcean).
- Free custom domain names and development software licenses.
