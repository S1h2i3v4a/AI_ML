# Notes 01.07: AI/ML Ke Liye Visual Studio Code Master Karna [Hinglish]

## 1. VS Code Hi Kyu Use Karein?

AI aur Machine Learning ke liye hum **Visual Studio Code (VS Code)** use karte hain kyunki yeh editor duniya bhar ke top engineers ka favorite hai. Iske andar:
- Fast text editing aur syntax highlighting milti hai.
- **Jupyter Notebooks (`.ipynb`)** direct VS Code ke andar bina browser open kiye run ho jaate hain!
- Terminal niche hi khula rehta hai, bar-bar window change nahi karni padti.
- In-built Git integration se code directly GitHub par push ho jata hai.

---

## 2. Zaroori VS Code Extensions

VS Code open karke left bar par Extensions icon (`Ctrl+Shift+X`) click karein aur ye do extensions install karein:
1. **Python (by Microsoft):** Code completion (IntelliSense) aur error detection deta hai.
2. **Jupyter (by Microsoft):** Interactive notebook cells (`Shift + Enter`) run karne ke liye.

---

## 3. Python Interpreter Kaise Select Karein?

Aksar students ka code isliye nahi chalta kyunki VS Code ko pata nahi hota ki kaunsa Python use karna hai.
1. `Ctrl + Shift + P` dabayein (Command Palette khulega).
2. Type karein: `Python: Select Interpreter`.
3. Apne project ke virtual environment wala Python select karein (`./myenv/Scripts/python.exe`).
4. Ab VS Code right-bottom corner mein aapka environment name dikhayega.

---

## 4. Useful Keyboard Shortcuts:
- `Ctrl + \`` : Integrated terminal open/close karna.
- `Shift + Enter` : Notebook cell run karke agle cell par jana.
- `Ctrl + Shift + P` : Sabhi VS Code commands access karna.
- `Alt + Up/Down` : Code line ko upar ya niche shift karna.
