# Notes 01.02: Curriculum Architecture: Hum Kya Seekhenge? [Hinglish]

## 1. AI/ML Ke 5 Core Pillars

Artificial Intelligence sikhna koi random YouTube tutorial dekhna nahi hai; yeh ek well-structured 5-stage architectural journey hai:

1. **Pillar 1: Python & Data Manipulation (Days 1–17)**  
   Python syntax, OOPs, NumPy ki high-speed vectorized computation, Pandas se tabular data analysis, aur SQL/APIs se data collection.
2. **Pillar 2: Mathematics for AI (Days 20–22)**  
   Bina math ke machine learning sirf library call karna bankar reh jata hai. Hum Probability (Bayes Theorem), Linear Algebra (Matrices, Eigenvalues), aur Calculus (Gradients, Optimization) ko deeply master karenge.
3. **Pillar 3: Data Visualization & EDA (Days 18–19)**  
   Matplotlib aur Seaborn se data ke patterns, correlations, aur outliers ko visually communicate karna seekhenge.
4. **Pillar 4: Classical Machine Learning (Days 23–35)**  
   Linear Regression, Logistic Regression, Decision Trees, Random Forest, Naive Bayes, kNN, SVM, aur Clustering algorithms ko theoretical math aur Python code dono ke sath build karenge.
5. **Pillar 5: Deep Learning, LLMs & MLOps (Days 36–60)**  
   Neural Networks, PyTorch, Computer Vision (CNN), NLP (Transformers, Self-Attention), Large Language Models (LLM Fine-tuning), aur Flask/Docker se models ko live internet par deploy karna!
