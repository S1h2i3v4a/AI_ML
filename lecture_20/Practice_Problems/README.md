This directory contains **3 comprehensive case-based and production-grade mathematical challenges** designed to master all foundational and advanced probability concepts taught across **Lecture 20** (Kolmogorov's Axioms, Conditional Probability, Law of Total Probability, Bayes' Theorem, Base Rate Fallacy, Random Variables, Expectation, Variance, Binomial Distribution, and Gaussian Calibration).

The module is partitioned into independent **Questions** and **Solutions** directories.
