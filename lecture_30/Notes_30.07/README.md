# Notes_30.07: Other Boosting Algorithms — XGBoost, LightGBM, CatBoost
## Supervised Machine Learning (Part 6) — Boosting & Advanced Ensembles

### 📌 Conceptual Summary
Comparative taxonomy of modern industrial boosting libraries: XGBoost (eXtreme Gradient Boosting with second-order Taylor expansion and exact/approximate quantile greedy splits), LightGBM (Microsoft's leaf-wise best-first growth and Histogram-based binning), and CatBoost (Yandex's symmetric oblivious trees and permutation-based categorical target encoding).

---

### 🛠️ Key Mathematical Formulations
- **Ensemble Hypothesis**: Sequential accumulation or weighted meta-combination.
- **Regularization**: Shrinkage learning rate, tree depth constraints, and out-of-fold validation.
