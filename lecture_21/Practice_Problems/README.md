## 📌 Overview

This directory contains **3 comprehensive case-based, production-grade mathematical challenges** designed to master foundational and advanced Linear Algebra concepts taught across **Lecture 21** (Vector Spaces, Norms, Inner Products, Affine Transformations, Homogeneous Coordinates, Matrix Inversion, Hyperplane Geometry, Orthogonal Projections, Support Vector Machines, Eigendecomposition, Covariance Matrices, and Principal Component Analysis).

The module is partitioned into independent **Questions** and **Solutions** directories.
