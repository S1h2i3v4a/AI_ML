## 📌 Overview

Is directory ke andar **3 comprehensive, production-grade industry case studies** hain jo **Lecture 25** ke sabhi core aur advanced classification concepts par command banate hain:
1. **Clinical Triaging & Cost-Sensitive Confusion Matrix Optimization** (Imbalanced Data, Bayes' Rule, Screening Paradox, Threshold Tuning)
2. **Bayesian Spam Filtering & Gaussian vs Multinomial Naive Bayes** (Conditional Independence, Laplace Smoothing, Log-Likelihoods, Zero-Frequency Problem)
3. **Metric-Space Nearest Neighbor Classification (kNN), Curse of Dimensionality & Leakage-Free Stratified K-Fold Pipelines** (Distance Distortion, High-Dimensional Metric Collapse, Data Leakage Prevention)

Yeh module do alag sub-directories mein divided hai: **Questions** aur **Solutions**.
