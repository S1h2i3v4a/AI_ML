## 🎯 Questions Ka Complete Index

1. **Problem 1 (BankAccount Class):** Account number, owner name, balance, deposit, withdraw, aur balance check methods.
2. **Problem 2 (Book Reviews Class):** Title, author, reviews list, add review, count reviews, aur display reviews methods.
3. **Problem 3 (Encapsulated Student):** Private attributes `_name`, `_roll_no`, `_marks` with validation getters aur setters.
4. **Problem 4 (Polymorphic Shape Area):** Base `Shape` class with `area()`, overridden by `Circle`, `Rectangle`, and `Triangle`.
5. **Problem 5 (Vehicle Inheritance):** Base `Vehicle` (`brand`, `model`), subclasses `Car` (`seats`) aur `Bike` (`engine_cc`).
6. **Problem 6 (Abstract Employee Payroll):** Abstract class `Employee` with abstract method `calculate_salary()`, implemented by `Intern`, `FullTimeEmployee`, and `ContractEmployee`.
7. **Problem 7 (Constructor Overloading Simulation):** `Person` constructor working with name only, name + age, name + age + address using default arguments.
8. **Problem 8 (Player Class Counter):** Class variable `player_count` tracking total players created across instances.
9. **Problem 9 (Multiple Inheritance):** `Herbivore`, `Carnivore`, aur `Bear` / `Omnivore` multiple inheritance MRO demonstration.
10. **Problem 10 (OOP Chat System Mini-Project):** `User`, `Message`, aur `ChatRoom` classes ke sath complete broadcast chat application.
