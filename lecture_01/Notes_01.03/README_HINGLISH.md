# Notes 01.03: Course Schedule, Pedagogy aur Study Roadmap [Hinglish]

## 1. 60-Day Study Strategy: Padhenge Kaise?

AI/ML sikhne mein sabse badi galti hoti hai sirf video dekhna aur sochna ki samajh aa gaya. Asli learning tab hoti hai jab aap khud apne haathon se code likhte hain aur error solve karte hain.

### Hamari Daily 3-Step Strategy:
1. **Mathematical Derivation:** Har formula ke peeche ka logic samjhein (jaise cost function gradient descent se zero kyu hota hai).
2. **Implementation in Code:** Pehle scratch se logic likhein, phir Scikit-Learn ya PyTorch se compare karein.
3. **Practice Problems:** Industry case studies solve karke real-world decision making seekhein.
